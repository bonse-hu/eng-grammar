# 英語文法トレーニング

英文を1問ずつ表示し、「和訳を見る」で答えを確認するPWAの初期版です。

## この版でできること

- JSONデータから英文をランダムに1問表示
- 和訳の表示・非表示
- 次の問題／前の問題
- iPhone向けの画面レイアウト
- PWAの基本設定（ビルド後の静的ファイルをキャッシュ）

## データの入れ替え

`src/data.json` を編集・差し替えてください。配列の各要素は次の5項目を持たせます。

```json
{
  "大分類": "文型",
  "中分類": "第1文型",
  "小分類": "SV",
  "英文": "I laughed.",
  "和訳": "私は笑った。"
}
```

## ローカルで動作確認

Node.js（LTS版）をインストールしたうえで、ターミナルでこのフォルダに移動して実行します。

```bash
npm install
npm run dev
```

表示されたローカルURLをブラウザで開きます。

## GitHub Pagesで公開する場合

1. GitHubリポジトリにこのフォルダ内のファイルをアップロードします。
2. `vite.config.ts` の `base` をリポジトリ名に合わせます。たとえばリポジトリ名が `english-grammar-app` なら `base: '/english-grammar-app/'` にします。独自ドメインやユーザーサイトの場合は `/` のままです。
3. このプロジェクトには `.github/workflows/deploy.yml` を入れてあります。GitHubリポジトリの Settings → Pages → Build and deployment で Source を **GitHub Actions** に設定すると、`main` ブランチへのpush時に自動でビルド・公開されます。

## 注意

- 現在はサンプルデータのみです。全例文を使うには `src/data.json` を全件版に置き換えてください。
- 分類選択（大分類・中分類・小分類のチェックボックス）は次の開発段階で追加します。
- オフライン利用は本番ビルド後に確認してください。初回アクセス時はインターネット接続が必要です。
- アイコン画像はまだ含めていません。ホーム画面用アイコンは後から追加できます。
